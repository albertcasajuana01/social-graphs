The Marvel Web

Each week we take one idea from the course and test it on a single network: 303 Marvel superheroes, the Wikipedia links between them, and the 730,000 words written about them.

Latest · Week 7 · From meaning to measurement

Can the text rebuild the network? Names, links and the Hawkeye problem

We found every character named in 29,006 sentences and rebuilt the network from names alone. 81.5% of links match a name. Where the two disagree, the name is usually a codename several characters share and the link says which one: 43 pages name Hawkeye, and none links to his page.

About this site

This is the group blog for DTU's course 02805 Social Graphs & Interactions. Each week's post asks one question about the Marvel network and answers it with that week's methods. The analysis code for every post is in the GitHub repository, and the README explains how to reproduce each one.

How to read the figures

  • Hover over any point, bar or line to see its exact values.
  • Click a pair or a character to open the details below the figure, including the original Wikipedia sentences.
  • Use the search boxes to find a character by name.
  • Every post ends with its limitations and a reproduce command.
